# ojAlgo-rocksdb

[![Maven Central](https://maven-badges.herokuapp.com/maven-central/org.ojalgo/ojalgo-rocksdb/badge.svg)](https://maven-badges.herokuapp.com/maven-central/org.ojalgo/ojalgo-rocksdb/)

```xml
<dependency>
    <groupId>org.ojalgo</groupId>
    <artifactId>ojalgo-rocksdb</artifactId>
    <version>X.Y.Z</version>
</dependency>
```

ojAlgo integration with [RocksDB](http://rocksdb.org). Provides a `java.util.Map` implementation backed by RocksDB.

RocksDB is a native library and needs to be installed on your system.

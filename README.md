# ojAlgo-extensions

ojAlgo has zero dependencies, but through extensions it integrates with other tools and libraries. Each of the modules below depend on ojAlgo and typically one 3:d party library.

- ojAlgo-commons-math3
- ojAlgo-cplex
- ojAlgo-gurobi
- ojAlgo-jfreechart
- ojAlgo-joptimizer
- ojAlgo-mosek
- ojAlgo-unsafe
- ojAlgo-yahoofinance

## Math/linear algebra interoperability

* [ojAlgo-commons-math3](https://github.com/optimatika/ojAlgo-extensions/tree/develop/ojAlgo-commons-math3) -> http://commons.apache.org/proper/commons-math/

You have access to this repository because you are an ojAlgo sponsor. Anyone is free to use the released artifacts and/or to maintain a fork of this repository, in accordance with the license. It's just direct access to this repository that is linked to being an ojAlgo sponsor.

New versions, of the various modules/artifacts, are built on request. To make such a request you also need to be a sponsor.

Support is available the same way it is for ojAlgo (the main/core library):

Some documentation is available in the form of blog posts at the ojAlgo web site: http://ojalgo.org/

Programming questions are best asked at [stack overflow](https://stackoverflow.com/search?tab=relevance&q=ojalgo). Just remember to actually mention ojAlgo and tag the question using 'ojalgo' and whatever other tags you find suitable.

Bug reports, or any issue with existing code, should be posted at GitHub: https://github.com/optimatika/ojAlgo-extensions/issues or https://github.com/optimatika/ojAlgo/issues

https://github.com/optimatika/ojAlgo-extensions/discussions (or https://github.com/optimatika/ojAlgo/discussions) may be used to discuss anything related to ojAlgo.

ojAlgo is Open Source, and you are strongly encouraged to clone or fork this repository and work directly with the source code. The source code is (part of) the documentation, and you should read it.

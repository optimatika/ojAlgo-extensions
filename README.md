# ojAlgo-extensions

Integrations that connect [ojAlgo](https://www.ojalgo.org/) to third-party solvers and libraries. ojAlgo itself has zero dependencies; each module here depends on ojAlgo and typically one third-party library. With a solver module on the classpath, the same `ExpressionsBasedModel` can be solved by that solver instead of ojAlgo's own.

## New releases

Each release is built against one specific version of its third-party library. [Optimatika subscribers](https://www.optimatika.se/subscription/) can request a new release of any module — for example one built against the solver version they run.

## Support

- Bugs: [issues](https://github.com/optimatika/ojAlgo-extensions/issues) – open to everyone, and every credible report is looked into.
- Questions: [Discussions](https://github.com/optimatika/ojAlgo/discussions) – answered for those who contribute something.
- Are the integrations part of your business? Then pay for support: [Optimatika subscribers](https://www.optimatika.se/subscription/) get private answers, and can request new releases.

More in [SUPPORT.md](https://github.com/optimatika/.github/blob/master/SUPPORT.md).
